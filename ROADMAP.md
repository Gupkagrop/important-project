# Roadmap развития Pocket Toolkit

План постепенного ежедневного расширения библиотеки `pocket-toolkit`. Каждый день агент реализует одну законченную задачу, сопровождает ее тестами на 100% покрытие и отправляет коммит в репозиторий.

---

## Этап 1: Базовые структуры данных (`structures`)
- [x] **День 1: Ring Buffer (Кольцевой буфер)** — Фиксированный кольцевой буфер `RingBuffer[T]` с поддержкой перезаписи старых элементов, итерации и проверки вместимости.
- [ ] **День 2: LRU Cache (Кэш вытеснения по давности)** — Класс `LRUCache[K, V]` с константным временем доступа `O(1)` на базе хеш-таблицы и двусвязного списка.
- [ ] **День 3: Prefix Tree / Trie (Префиксное дерево)** — Класс `Trie` для эффективного поиска по префиксу, проверки наличия слов и автодополнения.
- [ ] **День 4: Priority Queue (Очередь с приоритетами)** — Класс `PriorityQueue[T]` с поддержкой динамического обновления приоритета элементов.
- [ ] **День 5: Disjoint Set / Union-Find** — Структура `DisjointSet` с эвристиками объединения по рангу и сжатия путей.
- [ ] **День 6: Deque with Capacity Limit** — Двусторонняя очередь `BoundedDeque[T]` с безопасным извлечением с обоих концов.
- [ ] **День 7: Bloom Filter (Вероятностный фильтр)** — Класс `BloomFilter` с несколькими независимыми хеш-функциями для быстрой проверки принадлежности множеству.

---

## Этап 2: Алгоритмы и вычисления (`algorithms`)
- [ ] **День 8: Levenshtein Distance & Fuzzy Match** — Вычисление расстояния Левенштейна и нечеткий поиск похожих строк в коллекции.
- [ ] **День 9: Run-Length & Byte Encoding** — Модуль легковесного сжатия данных `rle_encode` и `rle_decode`.
- [ ] **День 10: Binary Search & Upper/Lower Bound** — Утилиты двоичного поиска в отсортированных последовательностях с предикатами.
- [ ] **День 11: Topological Sort (Топологическая сортировка)** — Алгоритм Кана для сортировки графа зависимостей и детекции циклов.
- [ ] **День 12: Interval Intersection & Merge** — Слияние перекрывающихся интервалов и поиск пересечений отрезков времени.
- [ ] **День 13: CRC32 & Simple Hashing** — Расчет контрольных сумм и хеширование данных без внешних библиотек.
- [ ] **День 14: Sliding Window Aggregator** — Расчет скользящего среднего, минимума и максимума за фиксированное окно времени.

---

## Этап 3: Функциональные утилиты и декораторы (`decorators` & `functional`)
- [ ] **День 15: Exponential Backoff Retry** — Декоратор `@retry` с экспоненциальной задержкой, джиттером и фильтрацией исключений.
- [ ] **День 16: Rate Limiter (Token Bucket)** — Декоратор ограничения частоты вызова функций на основе алгоритма корзины токенов.
- [ ] **День 17: Memoize with TTL** — Декоратор мемоизации `@timed_cache` с временем жизни кэша и ограничением размера.
- [ ] **День 18: Circuit Breaker** — Паттерн «Автоматический выключатель» для изоляции сбоящих внешних вызовов.
- [ ] **День 19: Debounce & Throttle** — Декораторы подавления дребезга и лимитирования частоты исполнения.
- [ ] **День 20: Pipe & Compose** — Функциональные операторы композиции и конвейера обработки данных `pipe(x, f, g)`.

---

## Этап 4: Работа с данными и строками (`data` & `strings`)
- [ ] **День 21: Text Slugify & Sanitizer** — Генерация URL-слагов с транслитерацией и очисткой небезопасных символов.
- [ ] **День 22: JSON Flattener & Unflattener** — Преобразование глубоких вложенных словарей в плоскую точечную нотацию (`a.b.c`) и обратно.
- [ ] **День 23: Human-Readable Byte & Time Formatter** — Форматирование байтов (`10.5 MB`) и промежутков времени (`2ч 15м 30с`).
- [ ] **День 24: Deep Merge & Deep Diff** — Рекурсивное объединение словарей и нахождение дельты между сложными структурами.
- [ ] **День 25: Safe Expression Evaluator** — Безопасный парсер и калькулятор простых математических выражений без использования `eval()`.
- [ ] **День 26: CSV to Dict & Dict to CSV streaming** — Потоковый легковесный преобразователь табличных данных.

---

## Этап 5: Системные и CLI утилиты (`cli` & `system`)
- [ ] **День 27: Console Table Formatter** — Красивая печать двумерных данных в виде ASCII/Unicode таблиц с выравниванием колонок.
- [ ] **День 28: Simple Progress Bar** — Текстовый индикатор выполнения задач в терминале с оценкой оставшегося времени.
- [ ] **День 29: ANSI Colorizer** — Модуль стилизации консольного вывода (жирный шрифт, цвета переднего плана и фона).
- [ ] **День 30: Env Config Parser** — Парсер переменных окружения со строгой валидацией типов (int, bool, float, list).
