# Roadmap развития Pocket Toolkit (60 дней)

План постепенного ежедневного расширения библиотеки `pocket-toolkit`. Каждый день агент реализует одну законченную изолированную задачу, сопровождает ее подробными комментариями и docstrings на русском языке, покрывает модульными тестами на 100% и отправляет коммит в удаленный репозиторий.

---

## Этап 1: Структуры данных (`structures`) — Дни 1–12
- [x] **День 1: Ring Buffer (Кольцевой буфер)** — Фиксированный кольцевой буфер `RingBuffer[T]` с поддержкой перезаписи старых элементов, итерации и проверки вместимости.
- [x] **День 2: Singly Linked List (Односвязный список)** — Односвязный список `LinkedList[T]` с поддержкой вставки в начало/конец, удаления по значению и прямого обхода.
- [x] **День 3: Doubly Linked List (Двусвязный список)** — Двусвязный список `DoublyLinkedList[T]` с быстрым удалением узлов за `O(1)` и двусторонней итерацией.
- [ ] **День 4: LRU Cache (Кэш вытеснения по давности)** — Класс `LRUCache[K, V]` с константным временем доступа `O(1)` на базе хэш-таблицы и двусвязного списка.
- [ ] **День 5: LFU Cache (Кэш вытеснения по частоте)** — Класс `LFUCache[K, V]` с вытеснением наименее часто запрашиваемых ключей за `O(1)`.
- [ ] **День 6: Prefix Tree / Trie (Префиксное дерево)** — Класс `Trie` для эффективного поиска по префиксу, проверки наличия слов и автодополнения.
- [ ] **День 7: Radix Tree (Сжатое префиксное дерево)** — Оптимизированное дерево `RadixTree` со слиянием узлов с общими префиксами.
- [ ] **День 8: Priority Queue (Очередь с приоритетами)** — Класс `PriorityQueue[T]` на базе бинарной кучи с поддержкой минимального/максимального приоритета.
- [ ] **День 9: Disjoint Set / Union-Find** — Структура `DisjointSet` с эвристиками объединения по рангу и сжатия путей.
- [ ] **День 10: Bounded Deque (Ограниченная двусторонняя очередь)** — Двусторонняя очередь `BoundedDeque[T]` с лимитом размера и безопасным выталкиванием.
- [ ] **День 11: Bloom Filter (Вероятностный фильтр)** — Класс `BloomFilter` с независимыми хеш-функциями для быстрой проверки принадлежности множеству.
- [ ] **День 12: Sparse Matrix (Разреженная матрица)** — Структура `SparseMatrix` на базе словаря координат для эффективного хранения нулевых матриц.

## Этап 2: Алгоритмы и вычисления (`algorithms`) — Дни 13–24
- [ ] **День 13: Binary Search Variants** — Утилиты двоичного поиска в отсортированных последовательностях: `lower_bound`, `upper_bound`, `binary_search`.
- [ ] **День 14: Levenshtein Distance & Similarity** — Вычисление расстояния Левенштейна и расчет коэффициента текстового сходства.
- [ ] **День 15: Run-Length Encoding / Decoding** — Модуль легковесного сжатия и распаковки данных `rle_encode` и `rle_decode`.
- [ ] **День 16: Topological Sort (Топологическая сортировка)** — Алгоритм Кана для разрешения зависимостей в направленном ациклическом графе (DAG).
- [ ] **День 17: Interval Intersection & Merging** — Алгоритмы слияния перекрывающихся интервалов и нахождения общего пересечения отрезков.
- [ ] **День 18: Sliding Window Aggregator** — Класс скользящего окна для расчета среднего, минимума и максимума за фиксированный интервал.
- [ ] **День 19: Knuth-Morris-Pratt (KMP) Search** — Быстрый поиск вхождений подстроки в строке с построением префикс-функции (массива $\pi$).
- [ ] **День 20: Simple Huffman Coding** — Построение дерева Хаффмана, кодирование и декодирование текстовых сообщений.
- [ ] **День 21: Dijkstra Shortest Path** — Поиск кратчайшего пути между вершинами во взвешенном графе с неотрицательными весами.
- [ ] **День 22: Fast Power & Modular Arithmetic** — Алгоритмы быстрого бинарного возведения в степень и нахождения обратного по модулю числа.
- [ ] **День 23: CRC32 & FNV-1a Hashing** — Собственные легковесные функции расчета контрольных сумм CRC32 и некриптографического хеша FNV-1a.
- [ ] **День 24: Reservoir Sampling & Fisher-Yates** — Алгоритм выборки $k$ случайных элементов из бесконечного потока и тасование массива за $O(n)$.

## Этап 3: Декораторы и функциональные утилиты (`decorators` & `functional`) — Дни 25–36
- [ ] **День 25: Retry with Exponential Backoff** — Декоратор `@retry` с экспоненциальной задержкой, добавлением джиттера и фильтрацией исключений.
- [ ] **День 26: Token Bucket Rate Limiter** — Декоратор ограничения частоты вызовов на основе алгоритма корзины токенов.
- [ ] **День 27: Leaky Bucket Limiter** — Ограничитель трафика и вызовов по алгоритму «протекающего ведра» с фиксированной скоростью утечки.
- [ ] **День 28: Timed Cache with TTL** — Декоратор мемоизации `@timed_cache` с временем жизни кэша и ограничением максимального размера.
- [ ] **День 29: Circuit Breaker Pattern** — Защитный выключатель (`CircuitBreaker`) с состояниями CLOSED, OPEN, HALF_OPEN для сетевых вызовов.
- [ ] **День 30: Debounce Decorator** — Декоратор подавления дребезга: откладывает выполнение функции до истечения паузы тишины.
- [ ] **День 31: Throttle Decorator** — Декоратор пропуска вызовов: гарантирует вызов функции не чаще одного раза за заданный интервал.
- [ ] **День 32: Pipe & Compose** — Функциональные утилиты для линейного конвейера обработки данных `pipe(val, f, g)` и композиции функций `compose(f, g)`.
- [ ] **День 33: Lazy Property Wrapper** — Дескриптор `@lazy_property` для отложенного вычисления атрибута объекта при первом обращении.
- [ ] **День 34: Function Currying** — Функция `curry` для преобразования функции нескольких аргументов в цепочку одноместных функций.
- [ ] **День 35: Execution Timer & Profiler** — Декоратор `@profile_time` для логирования и сбора статистики времени выполнения функций.
- [ ] **День 36: Deprecation & Contract Validator** — Декораторы `@deprecated` с выводом предупреждений и `@validate_types` для проверки сигнатур.

---

## Этап 4: Обработка данных и строки (`data` & `strings`) — Дни 37–48
- [ ] **День 37: Text Slugify & Transliteration** — Генерация чистых URL-слагов с транслитерацией кириллицы в латиницу.
- [ ] **День 38: String Case Converters** — Конвертер регистра строк: преобразование между `camelCase`, `snake_case`, `kebab-case`, `PascalCase`.
- [ ] **День 39: JSON Flattener & Unflattener** — Преобразование глубоких вложенных структур в плоские словари вида `{"a.b.c": 1}` и обратно.
- [ ] **День 40: Deep Dict Merge & Patch** — Рекурсивное слияние словарей и применение JSON-like дельта-патчей.
- [ ] **День 41: Dict Difference & Delta Finder** — Утилита поиска добавленных, удаленных и измененных ключей между двумя структурами.
- [ ] **День 42: Human-Readable Byte Formatter** — Форматирование размера данных в байтах (КБ, МБ, ГБ) с поддержкой стандартов SI и IEC.
- [ ] **День 43: Time Duration Formatter** — Преобразование секунд и миллисекунд в компактный вид (например, `2ч 15м 30с`).
- [ ] **День 44: Safe Math Expression Evaluator** — Безопасный парсер и калькулятор базовых арифметических выражений на базе AST без вызова `eval()`.
- [ ] **День 45: SemVer (Semantic Versioning) Parser** — Класс `SemanticVersion` для парсинга, сравнения и валидации версий по спецификации SemVer 2.0.
- [ ] **День 46: Simple Template Engine** — Легковесный шаблонизатор текста с подстановкой переменных `{{ var }}` и условными блоками `{% if %}`.
- [ ] **День 47: URL Query String Parser & Builder** — Разбор и сборка query-параметров URL с корректным экранированием символов.
- [ ] **День 48: Streaming CSV Parser & Generator** — Потоковый легковесный парсер и генератор CSV с поддержкой кавычек и экранирования.

## Этап 5: Системные, CLI и файловые утилиты (`cli` & `system`) — Дни 49–60
- [ ] **День 49: ANSI Colorizer & Text Styler** — Модуль стилизации консольного текста (цвета текста, фоны, жирный, подчеркивание) с автоопределением TTY.
- [ ] **День 50: CLI Table Formatter** — Форматирование и вывод двумерных данных в виде аккуратных ASCII/Unicode таблиц с автоподбором ширины колонок.
- [ ] **День 51: Text Progress Bar** — Текстовый индикатор выполнения задач в консоли с отображением процентов, шкалы и оценки оставшегося времени.
- [ ] **День 52: CLI Argument Parser** — Минималистичный и типобезопасный парсер позиционных аргументов и флагов командной строки.
- [ ] **День 53: Env File & Configuration Parser** — Парсер `.env` файлов со строгим приведением типов к `int`, `float`, `bool`, `list`.
- [ ] **День 54: Glob & Path Pattern Matcher** — Сопоставление путей файлов по шаблонам с поддержкой звездочек `*`, `**` и знака вопроса `?`.
- [ ] **День 55: Temp File & Directory Contexts** — Контекстные менеджеры для создания гарантированно удаляемых временных файлов и папок.
- [ ] **День 56: In-Memory File Buffer** — Виртуальный потоковый буфер данных с поддержкой позиционирования `seek`, чтения и поблочной записи.
- [ ] **День 57: Atomic File Writer** — Утилита безопасной атомарной записи файлов через временный файл с последующим переименованием.
- [ ] **День 58: Simple Structured Logger** — Легковесный логгер со структурированным выводом (JSON или текст) и цветовой дифференциацией уровней.
- [ ] **День 59: Event Bus / Observer** — Потокобезопасная синхронная шина событий с подпиской, отпиской и фильтрацией по типу события.
- [ ] **День 60: System Diagnostic Collector** — Сборщик системных метрик окружения (версия ОС, Python, память процесса, системное время) на стандартной библиотеке.
